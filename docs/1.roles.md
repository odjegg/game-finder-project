## 3. GitLab Workflow

<!-- A brief description of how the team will use GitLab for version control, issue tracking, and collaboration -->

- Branch per feature
- Merge branches once each branch is complete and push to main
- One person will announce which branch they are pushing to ahead of time so others can steer clear of it unless they are adding new content later.
- For incomplete documentation per branch, an issue will be raised to bring attention to it and have it solved as soon as possible.
